## How conflict detection works (brief)
- The server keeps a 'last_edit_times' map per document, keyed by line index.
- When a client updates, it provides `lines` — the indices that changed.
- If any incoming line or adjacent line was edited by another session within a short window (2 seconds), the server detects and broadcasts a `conflict` event and appends a `conflict` record to the JSONL log.
- Clients highlight the conflicting line indices (red-ish background) and print a console warning. This is a visualization/simulation — not an automated merge.
