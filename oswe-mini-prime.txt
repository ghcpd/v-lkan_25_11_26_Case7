## ✅ 功能实现总结

1. 实时协作
   - 使用 Flask-SocketIO 实现基于 WebSocket 的协作，支持多个 client 同时编辑。
   - 每个文档以 `doc_id` 为房间（room），变更广播到房间所有客户端。
2. 并发处理（简化 LWW）
   - 最后被服务器接收的编辑即作为“权威”状态（LWW，Last-Write-Wins）。
3. 在线/离线（Presence）
   - 无需登录：客户端自动生成短随机临时 ID（例如 `user-xxxxx`），并在 `localStorage` 保存。
   - PRESENCE 以 SID -> user 的映射存储（每个文档），并动态广播当前在线人数给房间里所有用户。
4. 客户端防抖（debounce）
   - 400ms 防抖：在 `editor` 的 `input` 事件中自动发送编辑更新，用户持续输入时会延后发送以减少事件频率。
5. 持久化 & 编辑日志
   - 每次编辑追加写入 `logs/<doc_id>.jsonl`（append-only JSONL）。
   - 服务器启动时会调用 `replay_logs()`，从 JSONL 恢复所有文档的最后状态和历史。
6. 冲突检测可视化（模拟）
   - 冲突定义：若多个编辑在时间窗口（CONFLICT_WINDOW_SECONDS，默认 3s）内编辑相同或相邻行，则认为冲突。
   - 检测：服务端根据 `edited_lines` 字段（行索引 start/end）检测冲突，并广播 `conflict` 事件到房间。
   - 可视化：客户端 preview 区显示冲突行背景高亮（红色），同时在控制台打印冲突信息（用于调试）。
   - 注意：可视化为“提示/模拟”，不是自动合并。
7. 匿名用户识别
   - 无认证，session 通过短 user-id 区分，所有编辑和历史记录均存储该 ID。

  - `sys.path.insert(0, str(Path(__file__).resolve().parents[1]))`, which points to the `collab/` directory, not the repo root. With that, `import collab` looks for a `collab` package inside the `collab/` folder (not found), causing `ModuleNotFoundError: No module named 'collab'`.
- Fix: I updated test_collab.py to add the repository root to `sys.path`. The test now uses:
  - `repo_root = Path(__file__).resolve().parents[2]`
  - `sys.path.insert(0, str(repo_root))`
