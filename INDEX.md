## 💡 KEY CONCEPTS

### Real-time Collaboration
Multiple users edit the same document. Changes sync instantly via WebSockets.
→ See: [README.md](README.md) → Real-time Collaboration

### Conflict Resolution
When users edit simultaneously, the most recent timestamp wins.
→ See: [ARCHITECTURE.md](ARCHITECTURE.md) → Conflict Detection Flow

### Persistence
Documents saved to JSON files. Edits logged to JSONL for replay.
→ See: [IMPLEMENTATION_GUIDE.md](IMPLEMENTATION_GUIDE.md) → Data Persistence Strategy

### Debouncing
Edits batched in 400ms windows to reduce server load.
→ See: [ARCHITECTURE.md](ARCHITECTURE.md) → Communication Flow

### Presence
Live count of active users per document with real-time updates.
→ See: [ARCHITECTURE.md](ARCHITECTURE.md) → Presence Tracking Flow
